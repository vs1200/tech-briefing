10月15日の発表を中心に、今週の見逃しを含めた技術ニュース10本です。

---

## 1. Figma Code LayersとSpecsがOpen Beta

[Figma公式](https://www.figma.com/blog/build-by-design/)によると、動くPrototypeをCanvasに置くCode Layersと、Markdownの仕様を共同編集するSpecsがOpen Betaになりました。

**開発者目線:** デザインと仕様、実装を同じ場所で比較でき、AgentへのContext共有にも役立ちます。

---

## 2. GitHub AI Scanが一般提供

[GitHub公式](https://github.blog/changelog/2026-10-15-ai-scan-for-pull-requests-generally-available/)によると、CodeQLの対象外も補うAI ScanがGAになりました。

**開発者目線:** DockerfileやTerraformなどの差分にもSecurity Reviewを広げられます。

---

## 3. GitHub Agentic Autofixが一般提供

[GitHub公式](https://github.blog/changelog/2026-10-15-agentic-autofix-for-code-scanning-alerts-general-availability/)によると、AlertをCopilotに割り当て、修正後にCodeQLで再検証する機能がGAになりました。

**開発者目線:** AIが修正した後の検証をWorkflowに組み込めます。

---

## 4. PhoneLLM MiniがWorkers AIに登場

[Cloudflare公式](https://developers.cloudflare.com/changelog/post/2026-10-15-phonellm-mini-workers-ai/)によると、音声Agent向けのPhoneLLM MiniがWorkers AIに追加されました。

**開発者目線:** 応答速度とTool Callingの正確さを重視する音声UIで比較対象になります。

---

## 5. Defold 1.14.0が公開

[Defold公式](https://defold.com/2026/10/12/Defold-1-14-0/)によると、Xbox対応やCubemap Render Target、macOSのMetal既定化が入りました。

**開発者目線:** 描画表現だけでなくNative Extensionの互換性も確認したい更新です。

---

## 6. GitHub Copilot旧モデルの廃止予定

[GitHub公式](https://github.blog/changelog/2026-10-15-upcoming-deprecation-of-selected-github-copilot-models-in-mid-november/)によると、旧モデル3種が11月16日に廃止予定です。

**開発者目線:** Model固定のWorkflowや組織Policyを点検する必要があります。

---

## 7. Crystal 1.22が公開

[Crystal公式](https://crystal-lang.org/2026/10/12/1.22.0-released/)によると、Native Event LoopやDWARF Parserの改善が入りました。

**開発者目線:** Runtimeの変更に伴う互換性を検証したいReleaseです。

---

## 8. KDE Plasma 6.8が公開

[KDE公式](https://kde.org/announcements/plasma/6/6.8.0/)によると、PlasmaのX11 Sessionが終了しWaylandへ一本化されました。

**開発者目線:** Linuxの画面操作やCapture Toolの互換性を見直す契機です。

---

## 9. Cloudflare GatewayとWorkersが連携

[Cloudflare公式](https://developers.cloudflare.com/changelog/post/2026-10-15-gateway-workers-public-beta/)によると、Gateway HTTP PolicyからWorkerを呼ぶPublic Betaが始まりました。

**開発者目線:** Network Policyと独自処理を組み合わせられます。

---

## 10. Cloudflare PagesのGitHub連携改善

[Cloudflare公式](https://developers.cloudflare.com/changelog/product/pages/)によると、Repository PickerがGitHub UserのAccess権限を反映するようになりました。

**開発者目線:** Repository連携時の権限に関する混乱を減らせます。

---

## 👀 今日ならこの3つ

### 🥇 Figma Code LayersとSpecs

仕様と動くCodeを一緒に扱う方向性が面白い更新です。

### 🥈 GitHub Agentic Autofix

修正後にCodeQLで検証するWorkflowが実務的です。

### 🥉 Defold 1.14.0

CubemapとEngine内部の改善に注目です。
