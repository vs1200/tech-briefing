# Tech Briefing

AI・ゲーム開発・開発ツールの話題を毎日 10 本まとめる個人用ニュースアーカイブです。

- フレームワーク: Astro / TypeScript / React / Tailwind CSS
- 公開先: GitHub Pages（検索エンジンには載せない設定）
- ニュースの追加方法と書式: [AGENTS.md](AGENTS.md)、[docs/news-template.md](docs/news-template.md)

```sh
pnpm install
pnpm dev      # http://localhost:4321/tech-briefing/
pnpm verify   # Lint・整形・型チェック・テスト
pnpm build
```
